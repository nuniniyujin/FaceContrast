# FaceContrast

**[WACV 2027] Interpretable Face Contrast Modeling for Smartphone Portrait Rendering**

Yujin Cho, Benoît Pochon, Jean-Michel Morel, Gabriele Facciolo

[![arXiv](https://img.shields.io/badge/arXiv-2610.26517-b31b1b.svg?style=plastic)](https://arxiv.org/abs/2610.26517)
[![Project Page](https://img.shields.io/badge/Project_Page-76b900.svg?style=plastic)](https://nuniniyujin.github.io/FaceContrast/)

FaceContrast decomposes facial contrast into three interpretable components: overall facial tonal separation, eye-region contrast, and micro-contrast of fine skin details. We validate these measures against human judgments and study how they combine to model balanced facial contrast preference.
